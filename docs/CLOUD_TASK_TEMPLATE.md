# 云端任务启动指令

将下段复制到新任务，填写目标与范围。它不要求重审全部项目，也不自动授权新分析或Git操作。

```text
本次目标：[填写一个明确目标]
允许修改/运行的范围：[填写目录、模块、分析或仅文档]
本次禁止事项：[填写；默认不重跑冻结分析、不改阈值/结论、不推送或合并]

请先阅读根AGENTS.md、docs/RESEARCH_PROGRESS.md的当前结论和模块导航、
docs/TASK_LOGS/README.md，再定向读取相关任务日志、代码及证据。
不要假设知道其他聊天上下文。核实当前checkout、工作区及已审核合并的共享基线；
不能核实就写未知。未提交/未合并结果明确标记，不能称最新共享状态。

在docs/TASK_LOGS/新建唯一任务日志（参考TEMPLATE.md），记录实际进展、
输入输出、参数/版本、验证、阴性结果、失败和限制；实质进展更新模块记录及
RESEARCH_PROGRESS入口。计算完成不等于科学假设成立，不追逐显著性。
现有表达程序关联路线停止自动优化；除非本次明确新授权，不继续该路线。

在授权范围内执行到可交接，不重复已完成工作。完成或中断前交代已做/未做、
文件路径、问题、后台/断点状态、下一步和同步状态。未经授权不提交、推送、
建PR或合并；只有已审核、提交并合并到GitHub约定集成分支的修改才是共享最新状态。
```

当前本地状态及共享证据见[科研进度](RESEARCH_PROGRESS.md)；本模板不是云端已部署或数据已恢复的证明。
