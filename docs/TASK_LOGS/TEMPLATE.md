# 任务交接模板（未执行任务）

复制为唯一文件名后填写；不适用写“不适用”，未知写“未核实”，不要预填成功。

## 任务与基线

- 日期/任务标识/方向：
- 用户目标、授权范围与禁止事项：
- 已读规则、科研进度版本及相关代码/结果：
- 起始分支/HEAD/工作区修改：
- 已核实的共享基线（目标分支、commit、审核/合并依据；或未知）：
- 本任务新增修改同步状态：LOCAL_ONLY / BRANCH_UNMERGED / MERGED_REVIEWED / UNVERIFIED（填写一项并给依据）

## 实际工作与证据

- 计算状态；科学状态（探索性/验证性/不适用）：
- 已完成、未完成及实际修改文件路径：
- 输入/输出、原件与副本关系、日志/结果路径：
- 方法、参数/随机种子/统计单位/校正范围、软件版本（仅文档任务写不适用）：
- 实际命令、验证结果及未验证范围：
- 阴性/不稳定结果、失败、技术混杂与统计局限：
- 是否修改既有结论；如是，依据及旧版本路径：

## 恢复与下一步

- 本任务后台任务/运行状态、断点及恢复入口：
- 当前问题、缺失资源/证据、不可估原因：
- 下一步建议与需要的授权；不要将建议写为已执行：
- 已更新的模块记录及RESEARCH_PROGRESS入口：
- Git实际操作；提交/PR/审核/合并位置（没有则明确写无）：
- 外置数据是否可用及独立校验状态：

- 本次确认覆盖的文件/结果；仍未同步的项目：
